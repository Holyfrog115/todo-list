# Web Todo List

A web version of todo list app featuring todo project folders, todo data details side window, sorting options, search bar and checklist subtasks. This project was built for ODP for educational purposes and heavily depends on DOM elements datasets.

[Live Demo](https://holyfrog115.github.io/todo-list/)

## Learning Objectives

- Work with npm packets
- Make structured project with modules
- Use in practice SOLID principles

## Features

### Project folders

Create new projects for your todo items, rename them and see all todos in default inbox project folder or all todays' todos in today folder.
